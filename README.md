# Auditoria-de-Estoque-com-SQL-e-Python
O projeto simula um inventário de uma empresa fictícia. O objetivo é verificar se o saldo registrado no ERP na data de corte coincide com a contagem física feita nos depósitos. O SQL será usado para reconstruir os saldos e classificar as diferenças. O Python executará a análise e exportará as exceções e os indicadores por depósito.
